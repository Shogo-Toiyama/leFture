## 🔍 1番目の概念：map / filter / reduce

まずは一番基本の3兄弟から、じっくりいきましょう！🎉

**3つの役割はこうです。**

- **map**：リストの**全要素に同じ変換**をかける（形はそのまま、中身が変わる）
- **filter**：条件に合う要素だけを**残す**（数は減るかもしれない）
- **reduce（Haskellでは foldr / foldl）**：リスト全体を**1つの値にまとめる**

```
[1, 2, 3, 4]  ──filter even──►  [2, 4]  ──map (*10)──►  [20, 40]  ──foldr (+) 0──►  60
```

型で書くと、役割がもっとはっきりします。

```haskell
map    :: (a -> b) -> [a] -> [b]
filter :: (a -> Bool) -> [a] -> [a]
foldr  :: (a -> b -> b) -> b -> [a] -> b
```

ポイントは、**`map` と `filter` は「リストを返す」けど、`foldr` は「1つの値を返す」**ことです。この違いが、テストで「最終的な型は何？」と聞かれたときの答えを決めます。

そして `foldr` の動きを一歩ずつ見ると、こんな感じです。

```
foldr (+) 0 [20, 40]
= 20 + (40 + 0)
= 20 + 40
= 60
```

右から順に畳み込んでいくイメージですね。🌀 `foldl` は左から畳むので、同じ `(+)` でも**かっこの付き方が変わる**と覚えておくと便利です。

Part Bの他言語のコードも、基本は同じ「filter → map → reduce」の流れです。読むときは、**データがどの順番で流れていくか**を矢印でたどると、スッと読めるようになりますよ！💪
