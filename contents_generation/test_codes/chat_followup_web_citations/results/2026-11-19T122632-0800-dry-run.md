# Previous Web citations dry-run

The candidate reused the Web citations stored on the preceding completed reply. The dry-run exercised the production excerpt formatting, numbering, and citation extraction code with a synthetic query client and with saved citation rows read from Supabase. Two runs used real citations, first against the candidate and then against the implementation.

| Initial Web reply | 3 | 270 | 0.878 ms |
| Reply after a more specific lookup | 3 | 439 | 1.019 ms |

The initial reply's cited headline survived the handoff. The later reply preserved cited passages with more detail. Synthetic checks covered exact passage selection, the snippet fallback, citation numbering and round-trip metadata, duplicate URLs, fresh-source precedence, the source and input budgets, and the handling of deleted rows and different threads.

The prompt identifies these excerpts as prior Web evidence and tells the answerer to use them only when relevant. Limits are three Web sources and approximately 650 tokens. The dry-run made no model or paid Web search calls and incurred zero model or search provider charges. The table excludes query latency and does not measure provider tokenization, model latency, or generated tone.
