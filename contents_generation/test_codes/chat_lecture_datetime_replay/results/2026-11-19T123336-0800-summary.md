# Chronological chat lecture numbering

The new map orders lectures by their recording timestamp. The dry-run covered an earlier recording saved later, equivalent timestamps written with different offsets, the repeated hour at the daylight-saving transition, missing dates, and invalid dates. Equal instants use the stored order as the first tie-breaker. Lectures with no usable date follow the dated lectures.

Supabase was read-only. The dry-run verified that a backfilled lecture moved from L16 to L13 and that the course topic tree placed it before the later lectures. It also rebuilt the follow-up answer prompt with three saved Web citations. The production answer message and navigator prompt builders were used, with a mock navigator response that successfully opened the real topic list. Automatic approval review initially blocked the model replay. The live replay ran after the user authorized the Anthropic payload.

The dry-run artifacts contain counts, estimated tokens, and retrieval time. Model latency, model tokens, and tone were not measured. The dry-run incurred no language model or Web search provider charges.
