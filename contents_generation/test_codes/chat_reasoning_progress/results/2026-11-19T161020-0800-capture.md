# Saved Haiku thinking summaries

Six recent completed responses from the confirmed account contained nonempty provider-rendered thinking summaries. The query matched Haiku 5.5 as the answer model and required a reasoning turn. The data came from `chat_messages.usage.reasoning.thought`. Read-only retrieval took 1,236 ms locally. Summary lengths ranged from 1,306 to 4,301 characters. The query retrieved no chat message body, profile, or unrelated account data.

The sample set included code reasoning and decisions about how to present practice problems. The prompt asks for the concrete check in one short user-facing sentence and uses NONE when there is no suitable progress to share. The supplied language is inserted into the system template, and the summary is passed separately as input. Local template validation covered Japanese and English.

The captured text is saved only in the git-ignored inputs directory. Pattern-based masking found no matching email or secret in the six samples. No model or Web search calls ran, so model cost was $0 and output quality, latency, and token usage were unmeasured.
