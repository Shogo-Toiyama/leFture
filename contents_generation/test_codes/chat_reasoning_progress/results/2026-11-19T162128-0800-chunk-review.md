# Two- and three-line chunk review

Six saved thinking summaries were split into 21 contiguous chunks. The split kept the original order and all 59 nonempty lines. A trailing single line was avoided by splitting the last four lines into a pair of two-line chunks. All chunks ended at a full stop in the source text. Later chunks sometimes referred to code or an issue introduced earlier in the turn.

The comparison uses the first three lines from each original sample. These excerpts have sufficient context to identify the topic. Some also contain presentation planning, which the prompt is intended to filter. Response parsing and request construction for the three providers were dry-run locally. No provider was called during this stage.
