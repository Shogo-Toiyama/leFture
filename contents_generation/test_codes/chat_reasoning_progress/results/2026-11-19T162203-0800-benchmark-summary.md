# Progress sentence benchmark

The experiment chose the first three complete nonempty lines from each of six saved summaries. The same six excerpts and the existing English progress prompt were sent twice to each provider after the user approved those destinations. Each call asked for Japanese and disabled reasoning. The local runner used the providers' native streaming APIs with a single reused HTTP client. Request order was shuffled before starting. The run issued 36 calls with no retries. It did not measure production network latency or the time to acquire three Haiku lines.

| Model | Text TTFT median | Finished line median | At most 500 ms | Input / output tokens | Cost |
| --- | ---: | ---: | ---: | ---: | ---: |
| Haiku 5.5 | 408 ms | 836 ms | 0/12 | 3,822 / 474 | $0.00061920 |
| Together Qwen3.5 9B | 288 ms | 519 ms | 5/12 | ~2,880 / ~349 | ~$0.00057685 |
| GPT-6 Luna | 730 ms | 1,169 ms | 0/12 | 2,656 / 472 | $0.00050160 |

Finished line time is the arrival of the last visible text fragment, determined after the stream ends. The provider's final stream marker may arrive later. Haiku returned one standalone NONE and one English line. Haiku's grounded Japanese lines were generally clearer, although some stated a conclusion or contained an extraneous phrase. Qwen was fastest and produced some concise progress lines. Other outputs contained garbled mixed-language wording, disclosed a calculation result, or substituted an operator unsupported by the excerpt. Luna appended NONE to a populated line in 10 of 12 outputs and repeated the same sentence in the other two. These are observations on the unmodified output, without automatic cleanup.

Together's streaming responses did not include token usage. Its token counts were estimated offline from the public Qwen tokenizer and chat template, including an estimated end token. Its figures may differ from billing and are not zero. The combined provider cost was approximately $0.00170. Full model output is in the ignored local inputs directory. No production implementation or prompt was changed.
