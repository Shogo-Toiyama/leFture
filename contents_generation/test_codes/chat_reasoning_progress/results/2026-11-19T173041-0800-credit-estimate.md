# Estimated marginal chat credits for progress labels

A read-only Supabase query covered the seven days ending November 19, 2026 at 17:30:41 Pacific. It returned 17 completed assistant replies and no stopped replies. Baseline average charged credits were 2.15715 per completed reply. Three replies matched the single-stage Haiku reasoning configuration and had at least one newline-terminated nonempty reasoning-summary line. One had enough lines for one potential progress request, and two had enough lines for three each. The median time between answer start and the first answer text for those three replies was 9,947 ms. The query took 450 ms. Message text and identifiers were not written to the results.

The saved ten-trial status-label benchmark used 3,872 input and 233 output tokens, for $0.00050370 at the public Haiku rates checked for this estimate. The chargeable fraction in the current code is provider token cost, converted using 300 credits per dollar and the 1.5 chat multiplier. The mean price of a completed label request was $0.00005037 or 0.0226665 credits. Cloud Run time is recorded separately and is excluded from user chat charges.

This estimate applies the same measured three-line request cost to all groups, including the first group of one line. It has no timing data for line arrivals, pending-group replacement, or the completion of the new label requests in production. Cancellation and shorter first-group inputs can reduce the calculated charge. The seven-day sample contains only three eligible turns, so it does not establish a stable population average. This analysis made no new model calls and incurred zero model tokens and zero provider cost.
