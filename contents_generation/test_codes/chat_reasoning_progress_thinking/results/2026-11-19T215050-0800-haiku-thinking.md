# Haiku progress label thinking regression

The Flutter client reads the progress label from a status event and substitutes it for the generic reasoning label. On the latest inspected developer turn, the answer route enabled reasoning, the provider summary had 13 complete nonempty lines, and the answer began after 17,263 ms. Four short Haiku token records appeared before the answer record, consistent with progress calls. Each used the full 96-token output budget. The database does not store the ephemeral progress label text or a client delivery receipt.

A dry run intercepted the actual LiteLLM 1.104.2 HTTP payload. The previous implementation translated `reasoning_effort="none"` to an omitted provider thinking field. Haiku 5.5 uses adaptive thinking when this field is omitted. The candidate set `thinking={"type":"disabled"}` explicitly without changing the 96-token ceiling or the prompt.

A synthetic Japanese trial produced a short, actionable progress phrase in all six requests across both variants. A separate replay used the same six previously approved three-line excerpts for both variants and reproduced the failure. Only summary metrics were recorded.

| Metric | Previous transport | Explicit thinking disabled |
| --- | ---: | ---: |
| Labels passing the display filter | 0/6 | 6/6 |
| Responses ending at the token limit | 5/6 | 0/6 |
| Median time to the complete result | 979 ms | 853 ms |
| Input / output tokens | 2,283 / 493 | 2,277 / 123 |
| Provider cost | $0.00047480 | $0.00028920 |

The two replay variants cost $0.00076400 in total. The synthetic calls added $0.00018070, bringing the experiment total to $0.00094470. The summarizer uses a nonstreaming request, so per-token TTFT was not measured. The replay filtered labels by shape and did not score their tone.

The production transport was updated to send the explicit disable flag when Haiku 5.5 is called with the existing none effort option. A post-change mock interception verified the production HTTP payload, and the four progress-stream tests passed. A live Cloud Run deployment of the change was outside this experiment.
