# Flutter router template design validation

A local Flutter widget test exercised the installed go_router 17.0.1 against synthetic routes. The test passed for initial navigation, a nested route with path parameters, a query-only change, an imperative push, pop, a redirect, and an unmatched route.

The delegate configuration's outer fullPath did not reflect the pushed route. Reading the final ImperativeRouteMatch's inner matches produced the visible route template and kept fixture IDs and query values out of the recorded screen sequence.

The test made zero external API calls, consumed zero model tokens, and incurred no API charges. The test runner displays elapsed time at one-second resolution and the experiment does not measure app runtime overhead.
