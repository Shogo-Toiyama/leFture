
## 🧭 基本の考え方

Haskellの `=` は「左側の式を、右側の値として定義する」という意味です。関数定義では、引数の後ろに `=` を書くと「この関数の本体はこれです」と宣言することになります。ガードや `if` を使うと、その `=` の位置が変わります。

---

## 🛡️ ガードのとき

ガードでは、関数名と引数の直後に `=` を書きません。代わりに、**条件ごとに** `|` の後ろに条件を書き、その条件の後ろに `=` を書きます。

```haskell
abs' n
  | n >= 0    = n
  | otherwise = negate n
```

`otherwise` の後ろにも `=` が必要です。`| otherwise` は「条件」で、そのあとの `= negate n` が「その条件のときの値」だからです。

---

## 🔀 if / else のとき

`if` を使う場合は、関数名と引数の直後に `=` が必要です。`if` の中では `=` は使わず、`then` と `else` で分けます。

```haskell
abs' n = if n >= 0 then n else negate n
```

ガードと `if` は、どちらか一方を選ぶ書き方です。ガードを使うなら、頭の `=` は付けません。

---

## ⚠️ 間違えやすいところ

- **比較には `==`** を使います。`x = 3` は代入ではなく定義として扱われるので、「等しいか」を調べるときは `x == 3` と書きます。`/=` は「等しくない」です。

```python
a = [1, 2]
b = a
b.append(3)  # 同じリストの中身を変えた
print(a)     # [1, 2, 3] になる
```

たぶん「前の値も変わる」と教わったのはケース2のことですね。`joke` も同じで、`c1.joke = "joke8"` のように属性を付け替えると、`com[0]` 経由で見ても変わって見えます。

ちなみに文字列（`"joke7"`）は変更できないタイプ（イミュータブル）なので、「中身を書き換える」ことはできません。`joke` を変えるときは、必ず新しい文字列の矢印を付け直すことになります。

もし実際のコードを貼ってもらえれば、`com[0]` と `c1` がどこで結びついているか、一緒に追いかけて確かめられますよ。


### 案B (回3)

ほぼ合っています！特に「com[0]はc1と同じCommedianオブジェクトを指している」という見方は、とても良い捉え方です。

混乱しやすいのは、**「参照先を変える」と「中身を変える」が別の操作**だという点です。

- **変数に代入し直す**（`c1 = Commedian(...)`）：変数c1が別のオブジェクトを指すようになるだけです。com[0]は古いオブジェクトを指したままなので、com[0]の中身は変わりません。
- **オブジェクトの属性を変える**（`c1.joke = "..."`）：c1とcom[0]は同じオブジェクトを指しているので、どちらから見ても変わったように見えます。

「Pythonはすべてが参照」というのは、リストの要素や変数が値そのものではなく、オブジェクトへの矢印（参照）を持っている、という意味です。矢印を付け替えると、その矢印を使っていた側だけが影響を受けます。

もう一つ大事なのが、"joke7"のようなStringは**書き換えられない（イミュータブル）**ということです。`c1.joke = "joke8"` と書くと、"joke7"のStringが書き換わるのではなく、jokeという属性の矢印が新しい"joke8"のStringを指すようになります。古い"joke7"は、他に誰も指していなければ、ただ捨てられるだけです。

次の例で動きを確かめてみてください（授業のコードとは違うかもしれないので、あくまで例です）。

```python
class Commedian:
    def __init__(self, joke):
        self.joke = joke

c1 = Commedian("joke7")
com = [c1]

c1.joke = "joke8"          # 中身を変える
print(com[0].joke)         # joke8（同じオブジェクトなので見える）

c1 = Commedian("joke9")    # 参照先を変える
print(com[0].joke)         # joke8（com[0]はまだ古いオブジェクトを指している）
```

最後の`print`で`joke8`と出れば、「参照先の付け替え」と「中身の変更」の違いがつかめたはずです。授業で見たコードがあれば貼ってくれたら、どこがどの矢印なのか一緒に追ってみましょう。
