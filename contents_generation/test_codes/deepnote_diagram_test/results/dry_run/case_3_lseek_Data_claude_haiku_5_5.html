lseek Data Access Flow [DRY RUN]

A flowchart showing the steps to access data using lseek in a file system with indirect blocks. Start with 'lseek(fd, offset, whence)'. Then 'Calculate logical block number'. Branch based on file size: 'Small File (Direct Block)' -> 'Access Inode, get data block pointer'. 'Medium File (Single Indirect)' -> 'Access Inode, get indirect block pointer, access indirect block, get data block pointer'. 'Large File (Double Indirect)' -> 'Access Inode, get double indirect block pointer, access double indirect block, get single indirect block pointer, access single indirect block, get data block pointer'. Finally, 'Access Data Block'.
