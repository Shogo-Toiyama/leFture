lseek Data Access Flow

Resolving a byte offset to a data block through direct, single indirect, and double indirect pointers

Step 1 · Position the file offset
lseek(fd, offset, whence)
Step 2 · Map byte to block
Calculate logical block number
logical block = offset ÷ block size (e.g., 8 KB)
Small File (Direct Block) Block number stored directly in inode
  1. Access inode
  2. Get data block pointer
Medium File (Single Indirect) Pointer reached through one indirect block
  1. Access inode
  2. Get indirect block pointer
  3. Access indirect block
  4. Get data block pointer
Large File (Double Indirect) Pointer reached through two levels of indirection
  1. Access inode
  2. Get double indirect block pointer
  3. Access double indirect block
  4. Get single indirect block pointer
  5. Access single indirect block
  6. Get data block pointer
Step 4 · Transfer
Access Data Block

Worst case: a byte in a large file requires the inode, the double indirect block, the single indirect block, and finally the data block itself.
