GPT Device Layout

Block-by-block structure of a GUID Partition Table device (512-byte blocks)

  • Block 0

    Protective Master Boot Record (MBR)

    A protective measure. Older systems that read this sector see an unknown partition type and will not attempt to boot from the device.

  • Block 1

    Primary GPT Header

    Contains the primary header of the GUID Partition Table.

  • Blocks 2–X

    Partition Labels / Tables

    Entries for 4 to 128 partitions, specifying the layout of the rest of the device.

  • Main Area

    Actual Partitions

    The largest portion of the device, dedicated to the actual data partitions.

  • Last Block

    Copy of Primary GPT Header

    A redundant copy stored in the very last block. If the primary header is corrupted, this backup is available for recovery.

Assumes a block size of 512 bytes
