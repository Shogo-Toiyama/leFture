lseek Data Access Flow

Finding a byte through inode and indirect blocks

lseek(fd, offset, whence)
Calculate logical block number
Small File (Direct Block)
Access inode → Get data block pointer
Medium File (Single Indirect)
Access inode → Get indirect pointer → Read indirect block → Get data block pointer
Large File (Double Indirect)
Access inode → Get double indirect pointer → Read double indirect block → Get single indirect pointer → Read single indirect block → Get data block pointer
Access Data Block

Worst case: 3 I/O accesses (inode → indirect → data)
