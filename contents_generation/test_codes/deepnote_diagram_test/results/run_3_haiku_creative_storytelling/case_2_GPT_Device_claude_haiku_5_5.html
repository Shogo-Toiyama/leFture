GPT Device Layout: A Block-by-Block Map

A GPT disk reads like a tidy shipping yard: safety seal first, index cards next, cargo in the middle, and a spare index card tucked at the far end.

⚠️ Exam trap: Block 1 holds the primary header; the last block holds its backup!
  • Block 0: Protective MBR
  • Block 1: Primary GPT Header
  • Blocks 2 to X: Partition Labels/Tables (4 to 128 entries)
  • Main Area: Actual Partitions

Bottom line! The GPT is sandwiched by two headers (first and last block), so one damaged copy never leaves the disk unbootable.
