Block size: 8 KB
START lseek(fd, offset, whence)
Position the file at the target byte offset.
▼
STEP 1 Calculate logical block number
Block number = byte offset ÷ block size
▼ branch by file size

Small File (Direct Block)

Access Inode ➔ Get data block pointer

Medium File (Single Indirect)

Access Inode ➔ Get indirect block pointer ➔ Access indirect block ➔ Get data block pointer

Large File (Double Indirect)

Access Inode ➔ Get double indirect block pointer ➔ Access double indirect block ➔ Get single indirect block pointer ➔ Access single indirect block ➔ Get data block pointer
▼ all lanes merge
✅ Access Data Block
⚠️ Exam trap: Each indirect level adds one more disk I/O. Deeper files cost more, but small files stay fast!

Bottom line! Bigger files need more hops through indirect blocks before the data arrives, and that's the price of fast access for small files.
