▼ branch by file size

Access Inode ➔ Get data block pointer

Medium File (Single Indirect)

Access Inode ➔ Get indirect block pointer ➔ Access indirect block ➔ Get data block pointer

Large File (Double Indirect)

⚠️ Exam trap: Each indirect level adds one more disk I/O. Deeper files cost more, but small files stay fast!

Bottom line! Bigger files need more hops through indirect blocks before the data arrives, and that's the price of fast access for small files.

⚡ 活動電位のフェーズ ノート要点

静止 → 脱分極 → ピーク → 再分極 → 過分極 → 回復

脱分極（Na⁺流入） 再分極（K⁺流出） 過分極 回復（ATPアーゼ）
  • ① 静止：Na⁺/K⁺ の透過性はほぼ静止状態。Na⁺・K⁺ ATPアーゼが勾配を維持
  • ② 脱分極：電位依存性 Na⁺チャネルが開き、Na⁺が流入して膜電位が上昇。Na⁺ チャネル
  • ③ ピーク：99%以上の Na⁺チャネルが開き、膜電位はナトリウム平衡電位へ。Na⁺ チャネル（最大）
  • ④ 再分極：Na⁺チャネルが不活性化し、K⁺チャネルが開いて K⁺が流出。K⁺ チャネル
  • ⑤ 過分極：K⁺チャネルがまだ開いたままで、膜電位が静止より一時的に負に。K⁺ チャネル（遅れて閉じる）
  • ⑥ 回復：K⁺チャネルが閉じ、Na⁺・K⁺ ATPアーゼが濃度勾配を取り戻す。
⚠️ 試験の罠 Na⁺チャネルは「速く開いて、速く不活性化」。K⁺チャネルは「遅れて開き、閉じるのも遅い」。この時間差が過分極を生みます。

Bottom line!Na⁺が先に流れ込んで膜電位を一気に押し上げ、遅れて出てくる K⁺ が元の電位へ引き戻す。

※ 縦軸・時間軸は概念図です。
