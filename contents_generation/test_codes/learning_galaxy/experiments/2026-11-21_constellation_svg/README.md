# 実験: ネオンSVG星座絵プロトタイプ (2026-11-21)

## 目的
「ソフトウェアエンジニアリング座（Architectura）」を題材とし、強結合の星々（8個）とSVGによるネオン調星座絵・結線・詳細カードの組み合わせが、ビジュアルおよびUXとして成立するかを検証する。

## 構成
- `index.html`: ブラウザで直接開いて動作確認できるインタラクティブビューワー。
  - **背景**: ディープスペース（星雲グラデーション）
  - **ネオン星座絵 (SVG)**: 建築家の天球儀・コンパスと波括弧 `{ }`（コードブロック）を融合した神話的幾何学モチーフ。
  - **星座結線 (エッジ)**: 8つの主星を結ぶネオングローライン。
  - **星ノード (8つの学び)**: α星（設計原則）を中心に、アルゴリズム、抽象化、TDD、リファクタリング、非同期、分散システム、コードレビューの星を配置。
  - **インタラクション**:
    - 各星をクリックすると「学んだ物語・ユーザーの発言引用」カードがポップアップ。
    - 「ネオン星座絵」「結線」「ラベル」の表示・非表示をワンクリックでトグル可能。
