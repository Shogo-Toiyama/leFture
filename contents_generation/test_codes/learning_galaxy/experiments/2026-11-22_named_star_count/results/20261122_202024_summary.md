# 名前のある星・名前のない星の数（開発者本人のチャット）

実行: 2026-11-22 20:20 / 生データ: `20261122_202024_stars.json` / 設計: `../../../03_design.md` の案2

## 何を測ったか
開発者本人の全チャット（40スレッド・489往復・2026-09-28〜11-20 の54日間、ほぼ宿題とテスト勉強）から、
1. 名前のある星（本人の内面から出た考え・願い・問い・気づき・経験・気持ち・価値観）が何個生まれるか
2. 各星に、案2の5種類の根拠で数えた名前のない星がいくつ付くか（根拠1つ＝星1個で数えた）

- 抽出: `gpt-6-luna`（reasoning low、本番の自己像の観察役と同じ設定）で1スレッド1回。入力も観察役と同じ形（本人の発言は全文、AIの返答は400字まで）。
- 引用の検証: 根拠の引用が本人の発言に一字一句あるかをコードで確認。191件中2件が見つからず捨てた。
- 未来とのつながり: 星と `user_profiles` の `future_goals`・`interests` の各文（6文）の embedding の類似度（`gemini-embedding-2`）。
- 過去の自分とのつながり: 別の日の名前のある星と類似度が閾値以上になった日数。

## 分かったこと
1. **宿題中心のチャットでも、名前のある星は1日2個近く生まれる**。半分近くは授業内容への自分の問いだが、人生・将来の星も20個あった。
2. **根拠を1つ＝星1個で数えると、年間2万個には全く届かない**（チャットだけで年約2,400個）。チャットだけで2万個にするなら、根拠1つあたり約11個の星が必要。講義の星と合わせる場合はもっと小さくてよい。
3. **「自分の言葉」と「推測を数えない」が機能していない**。根拠189件のうち initiative=user が188件、grounding=explicit が185件で、ほぼ全部が数えられた。「自分の言葉」は実質「発言の数」になり、長い宿題スレッドほど増える。
4. **「未来とのつながり」は閾値0.75でよく効く**。0.75以上になった星は、ほぼキャリアの会話の星だけだった。ただし基準の `future_goals` は AI が本人のチャットから書いたもの（`future_goals_written_by = ai`）なので、同じチャットから出た星と近くなるのは当然という面がある。
5. **「過去の自分とのつながり」は閾値0.80が妥当**。0.80では「一つずつ丁寧に確かめたい学び方」や「再帰の理解」のように、本当に何度も戻ってきたテーマを拾えた。0.75では関係の薄い勉強の星どうしまでつながった（195）。
6. **1往復あたりで見ると内面の会話の方が4倍多いが、名前のある星1つあたりでは差がない**。キャリアの会話は1つのテーマが7つの星に分かれ、それぞれの根拠が1〜3個になった。授業の問いの星の一部（「ルーターはTCPを…」6個）がキャリアの星（「エンタメの体験を創る」3個）より多い。
7. 同じテーマ（丁寧に一つずつ学びたい、など）が別のスレッドで6つ前後の名前のある星になっている。スレッドをまたいで同じテーマを1つの星にまとめるかどうかを決める必要がある。
8. 宗教に触れた星（「物語への興味と信仰との距離」）が1つあった。本番の観察役にあるセンシティブな分野の扱いが、この抽出には無い。

## 次に試すこと（案）
- 根拠の種類ごとの重み（k）を変える。「自分の言葉」は発言の数ではなく、内面の話題に使った文字数や往復数で数える。
- 星の種類（人生・将来・価値観 / 学び方 / 授業内容への問い）で基本の大きさを変える。
- スレッドをまたいで同じテーマの星をまとめ、まとめた分を「過去の自分とのつながり」に回す。
- 推測かどうかの判定は LLM に任せず、引用の中に自分についての言葉（「〜したい」「〜と思う」など）があるかで決める。
