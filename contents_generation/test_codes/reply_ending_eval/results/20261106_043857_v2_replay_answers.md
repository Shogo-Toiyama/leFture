## 2つは別の概念です

- **Type inference（型推論）**：型を**書かなくても**、コンパイラが値や使われ方から型を決めてくれる仕組み
- **Static typing（静的型付け）**：型が**変数に固定**されていて、型チェックを実行前に行う性質

```
count := 3       ← 型推論：右辺の 3 から int と決める 🎯
                 ← 静的型付け：その int が以後ずっと固定 📦
```

つまり、型推論は「型を**どうやって決めるか**」の話で、静的型付けは「決まった型を**どう扱うか**」の話です。型推論は、静的型付けの言語でよく使われる、という関係です。

## 私の説明のどこが混ざっていたか

先ほどの「変数の型は固定」は、**静的型付けの性質**のほうです。型推論の回（10/20）で扱った話ですが、「型推論があっても変数の型は固定される」という形で、静的型付けの話と重なって見えていました。

そして授業では、型推論は10/20、固定と静的型付けは10/22の話として扱われているので、TYPING7で問われるのは主に**型推論**のほうだと思っておくと安心です。
