## 型昇格（Type promotion）ってなに？

**狭い型から、広い型へ自動で変換すること**です。大事なのは、**値が失われない**という点です。

講義の定義でも、変換先の型は元の型のすべての値を表せることが条件になっています。

イメージは、**小さなコップの水を大きなバケツに移す**感じです。🪣💧 こぼれないから安心ですよね！

```
  int（小さいコップ）  ──昇格──▶  double（大きいバケツ）
        5               ──────▶      5.0    ✅ 何も失われない！
```

---

## 具体例で見てみよう 🧪

```cpp
int i = 5;
double d = 3.14;
std::cout << i + d;   // 8.14 と表示される
```

`i + d` を計算するとき、コンパイラが `i` をこっそり `double` に変えてから足し算をします。結果が `double` になるのはそのためです。`double` は `int` のすべての値を表せるので、この変換は安全です。

---

## どの型に合わせるの？（優先順位） 🎯

C++ では、次の順にルールを上から確認して、最初に当てはまったものに合わせます。

1. どちらかが `long double` → もう片方も `long double` にする
2. どちらかが `double` → もう片方も `double` にする
3. どちらかが `float` → もう片方も `float` にする

`i + d` は2番目のルールが当てはまるので、`i` が `double` になります。

---

## 型昇格は「強制変換」の仲間 👨‍👩‍👧

```
強制変換（自動の変換）
 ├─ 型昇格 🌱    狭い → 広い、値は失われない（int → double）
 └─ 縮小変換 ⚠️  値が失われるかも（int → bool など）
```

つまり、型昇格は強制変換の中の一つです。

ひとつ注意点があります。`int` → `float` は、大きな整数を正確に持てないことがあります。たとえば `16777217` は `float` にすると `16777216` になってしまいます。そのため、きれいな昇格の例としては `int` → `double` のほうが分かりやすいです。📝

### Production (baseline)

```
① 詰まった問題を1つ出す（問題文 or 自分の答えを貼ってOK📝）

④ 最後に似た問題で、ちゃんとできたかをチェック🎯
```

答えをそのまま出すより、**どこでつまずいたかを一緒に見つける**ほうが、テストで効きます！
