## Findings that shaped the design
- v2 `GET /customers/{alias uuid}/subscriptions` resolves aliases (fdae3630 → original `$RCAnonymousID:…01fe`).
- Unknown customer → 404 `resource_missing`, no customer created (v1 GET would create one).
- `subscription.product_id` is RevenueCat's internal id (`prod61c65a81de`), not the store id →
  needs `project_configuration:products:read` (current key → 403). NOT YET VERIFIED: the
  product response field name `store_identifier`.
- RC can be stale too: 4859e134 Stripe sandbox sub has `gives_access: true` but period ended 2026-10-19.
- Pagination: 20/page default; lefture.app has 23 subs (tested with limit=10 → 3 pages).
- RC latency per customer: 124–411 ms (one page), measured in S3.

## SECURITY (critical)
Billing SECURITY DEFINER functions were executable with the public anon key via
`/rest/v1/rpc/...` (probe with a non-existent product reached `unknown_store_product`; no write).
Migration `20261110000000_revoke_public_execute_on_functions.sql` revokes EXECUTE from
PUBLIC/anon/authenticated on all non-trigger, non-extension public functions; allowlist
(authenticated): get_my_tier_level, touch_activity, search_knowledge_chunks. Also fixes default
privileges (per-schema defaults cannot revoke the built-in PUBLIC grant → role-wide revoke needed;
caught by S1 `future_fn`).
