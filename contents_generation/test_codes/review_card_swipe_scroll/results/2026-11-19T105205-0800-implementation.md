# Application code verification

Applied the verified card-specific scroll offset patch to the Flutter project.
Each mounted review card reads its last offset from the viewer's in-memory
map and updates that map as its vertical position changes. The listener does
not trigger a rebuild.

From `user_interface`:

```sh
flutter test --no-pub --reporter expanded \
  ../contents_generation/test_codes/review_card_swipe_scroll/review_card_swipe_scroll_test.dart \
  ../contents_generation/test_codes/review_card_navigation_images/review_card_navigation_images_test.dart
dart analyze lib/presentation/pages/review_cards/review_cards_viewer_page.dart
```

Both suites passed together, with 8/8 tests reporting completion at 00:03.
