# Matched follow-up retrieval comparison

Three synthetic pairs keep the first question and the follow-up identical. Within each pair, the previous answer either supplies the requested fact or omits it. Expected labels were fixed before the runs. Both variants used the production router function and Gemini 3.1 Flash-Lite. After mock validation, each variant ran once per case.

| Case | Expected retrieval | Original prompt | Priority prompt |
| --- | --- | --- | --- |
| Library cause missing | Yes | Yes | Yes |
| Library cause present | No | Yes | No |
| Scholarship resubmission policy missing | Yes | Yes | Yes |
| Scholarship resubmission policy present | No | No | No |
| Instructor rationale missing | Yes | Yes | Yes |
| Instructor rationale present | No | Yes | Yes |

The priority prompt removed one unnecessary retrieval decision. Both prompts continued to request retrieval for the already-stated instructor rationale. Neither missed any of the three cases where the fact was absent. All calls returned valid decisions in the expected reply language.

| Prompt | Correct | Unnecessary retrieval | Median latency | Input / output tokens | Provider cost |
| --- | ---: | ---: | ---: | ---: | ---: |
| Original | 4/6 | 2 | 1.211 s | 13,739 / 699 | $0.00448325 |
| Priority | 5/6 | 1 | 1.349 s | 15,293 / 698 | $0.00487025 |

The total recorded provider cost was $0.00935350 for 12 calls. These are single-trial routing results from synthetic cases. No search or answer model calls were made. Production prompts and settings were unchanged.
