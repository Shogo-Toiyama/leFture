# Independent router follow-up suite

Ten new synthetic conversations were labeled before running the model. Five required additional retrieval and five could be handled with the available context or general knowledge. The cases cover implicit lecture references, textbook explanations, a visible selection, attachment visibility, recent news, a previously cited fact, an explicit request to skip searches, past-chat recall, and a current deadline.

The already-tested priority prompt was frozen for this run. The experiment used production router rendering, JSON schema, normalization, transport, and billing. A mocked dry-run passed before the live run. Only the revised Gemini 3.1 Flash-Lite prompt ran against the model. All 10 cases matched the gold retrieval label, with no missed retrieval, unnecessary retrieval, fallback, or reply-language error. No case qualified for an original-prompt retest.

Ten model calls used 25,370 input and 1,162 output tokens, for $0.00808550 in recorded provider cost. Median router latency was 1.178 s, and nearest-rank p95 was 1.379 s. The router did not generate an answer or execute searches. The suite used synthetic conversation data and one trial per case. Production configuration and prompts were untouched.
