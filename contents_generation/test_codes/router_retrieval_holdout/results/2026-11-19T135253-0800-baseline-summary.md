# Selective baseline comparison

Three existing holdout fixtures were selected before testing. They probe the conflict between continuing a conversation and retrieving a missing fact, and the boundary between reusing a supported fact and retrieving it anew. Each fixture ran once with the original production prompt and model after a mocked dry-run.

| Case | Expected retrieval | Original prompt | Priority prompt from prior run |
| --- | --- | --- | --- |
| Implicit question about the instructor's reasoning | Yes | Yes | Yes |
| Reason missing from a recent public announcement | Yes | Yes | Yes |
| Confirmation of a reason already supplied by a citation | No | No | No |

The original prompt matched all three gold labels. This comparison showed no difference on the selected holdout cases. The earlier saved production replay remains a separate observed difference. Both comparisons used one trial per condition and case.

Three model calls used 6,814 input and 331 output tokens. Recorded provider cost was $0.00220000 and median routing latency was 1.270 s. No fallback or reply-language error occurred. This classification run made no search or answer model calls. Production configuration and prompts were unchanged.
