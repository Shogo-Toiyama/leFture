macOS の画面収録の許可がないときのエラー確認

webapp の録音と同じ設定で getDisplayMedia() を呼び、失敗したときのエラー名・文言・失敗までの時間を results/ に保存します。

  1. システム設定 → プライバシーとセキュリティ → 画面収録とシステムオーディオ録音 で Google Chrome を OFF
  2. Chrome を ⌘Q で終了して開き直し、このページを開く
  3. シナリオ名を確認して「共有ダイアログを開く」を押す（ダイアログが出たら、そのまま何もせず様子を見る）
  4. 比較用に、許可を ON に戻して再起動したあと、ダイアログを自分で「キャンセル」した場合も1回記録する
