System Audio Capture Test

ブラウザ（getDisplayMedia）で、PCが鳴らしている音を録音できるか確かめるページです。

手順

  1. シナリオ欄に、今回の条件（例: zoom-app_earphones）を入れる
  2. 「キャプチャ開始」を押し、共有ダイアログで 画面全体 か ウィンドウ を選んで、「システム音声を共有」をONにする（タブを選んだ場合は「タブの音声も共有」をON）
  3. Zoom・YouTube・下の「テスト音」などを鳴らし、メーターが動くか見る
  4. 「停止して保存」を押すと、録音ファイルと結果のJSONが results/ に保存される
