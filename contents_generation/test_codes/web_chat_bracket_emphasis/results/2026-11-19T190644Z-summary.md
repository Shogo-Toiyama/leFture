# Shared bracket emphasis in Web AI Chat

Run `node contents_generation/test_codes/web_chat_bracket_emphasis/run.mjs`
from the repository root. It bundles and renders the production
`ChatMessageItem`, `CitationPreviewModal`, and `AnnotatedMarkdown`
components in Node with synthetic content.

Before the change, the Chat preprocessor rendered only `サンク(thunk` and
`遅延評価` as bold in the example. The Chat views now share the bracket-aware
Markdown plugin already used by Review Cards and Deep Notes. The Chat
preprocessor continues to move edge punctuation such as `。` outside the span
and leaves supported brackets for the shared parser.

All six cases passed, including complete and streaming replies, the care
message variant, the citation preview, the shared annotated renderer, and
mixed punctuation, inline code, math, and citation markers. Baseline and
updated runs took 284 ms and 401 ms including bundling. The production Web
build passed, with Vite reporting 3.69 s. No external API calls, LLM tokens,
or API costs.
