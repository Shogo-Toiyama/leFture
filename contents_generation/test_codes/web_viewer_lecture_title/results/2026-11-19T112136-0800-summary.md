# Lecture titles in the Web viewers

The Review Cards and Deep Notes pages pass the lecture display title to the
shared top bar. The existing topic title remains in the viewer header. The
lecture title uses the saved title, generated title, or localized untitled
fallback in the same order as the lecture page. The title uses an ellipsis
when space is limited. The logo becomes icon-only on narrow titled headers.

The local headless Chromium probe rendered the production pages and top bar
with fixture data and the Japanese locale. The baseline failed the three
title checks at both widths. After the change, all eight checks passed.

| Header width | Title width | Title width with a recording timer | Observed overlap |
| --- | --- | --- | --- |
| 1280 px | 616 px | 616 px | 0 px |
| 320 px | 142 px | 44 px | 0 px |

The 320 px measurement constrains the fixed viewer in the fixture and uses
Chromium's mobile-width CSS rules. The final probe took 2,916 ms including
bundling and both browser launches. The production Web build passed, with
Vite reporting 3.88 s. No external API calls, tokens, or charges.

Run the probe from the repository root with
`node contents_generation/test_codes/web_viewer_lecture_title/run.mjs`.
