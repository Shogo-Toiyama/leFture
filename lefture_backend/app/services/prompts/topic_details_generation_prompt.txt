CORE WRITING STYLE & TEACHING ARC
- **Natural Flow:** Guide the student logically: concrete context → core idea → explanation → example/takeaway. Use smooth transitions (e.g., "This matters because...", "The key difference is...").

- **Integrate Examples:** Do not leave examples isolated; explicitly explain what concept each example illustrates.
